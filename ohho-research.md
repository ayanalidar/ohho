# OHHO Foods — Company Research Dossier

**Source website:** https://www.ohhofoods.com
**Research method:** Page-reader fetch of the live homepage (single-page application), plus 6 supplementary web searches (Google + Instagram snippets) cross-referenced for accuracy.
**Date compiled:** Based on the site's footer copyright "© 2025 Ohho Foods"
**Notes / caveats:** The website is a single-page app built with Lovable.dev (hosted on Vercel/lovable.dev). Sub-routes (`/menu`, `/franchise`, `/about`) return 404 — all real content lives on the homepage. The site contains aspirational/forward-looking marketing copy (e.g. major-metro hub cards with revenue figures); cross-referenced public sources indicate the brand's *actual operational origin* is **Shamli & Kairana, Uttar Pradesh**, and it is currently rolling out franchise partnerships Pan-India. Treat the metro "hub" cards as marketing/positioning rather than verified operational outlets.

## 5. Brand Identity — Visual Style, Colors & Logo

### Logo
- A PNG logo asset is hosted at: `https://www.ohhofoods.com/assets/logo-D2O7IJJE.png`
- The wordmark uses **"OHHO"** (all caps, 4 letters) in a heavy/bold sans-serif — visible in the navbar and footer.

### Brand color palette (extracted from inline CSS + Tailwind custom tokens)

The site defines a custom Tailwind color system using the `ohho-*` namespace:

| Token | Hex / RGB | Usage |
|---|---|---|
| **ohho-orange** | `#ff6a00` / `rgb(255, 106, 0)` | **Primary brand color** — CTAs, accents, hover states, primary buttons, gradients |
| **ohho-gold** | `#ffc107` / `rgb(255, 193, 7)` | **Secondary brand color** — premium accents, highlights, dividers, gold-text headings |
| **ohho-red** | (red accent — appears as `from-red-500`/`to-ohho-red` gradient endpoints, used in gradient overlays) | Hot/energy accent in gradient meshes |
| **ohho-black** | `rgb(14, 10, 4)` — very dark near-black warm brown | **Page background** — deep premium dark backdrop |
| **ohho-black-light** | `rgb(26, 16, 5)` | Secondary dark surface (cards, navbar overlay) |
| **ohho-cream** | `rgb(245, 230, 204)` — warm cream / parchment | **Body text on dark backgrounds**, soft contrast text |
| **White** | `#ffffff` | Highlights, primary text in dark sections |

**Color usage pattern (premium QSR feel):**
- Dark luxury background (warm near-black `rgb(14,10,4)`)
- Vibrant **orange-to-red gradient** for energy/CTA elements
- **Gold** accents to signal "premium"
- **Cream** text on dark surfaces for readability
- Frosted-glass / translucent dark overlays (`bg-ohho-black/50`, `bg-white/20`) for cards

### Typography & layout style
- Modern, bold sans-serif (looks like a system / Inter / Poppins family)
- Generous use of emoji prefix icons on menu items (🍗 🔥 😋 🍞 ⭐ 🍕 👑 🥔 ☕ 💪 ⚡)
- Gradient-text headings using `bg-clip-text` (orange→gold→red gradients on hero text)
- Glassmorphism cards (`backdrop-blur` + semi-transparent dark backgrounds + gold/orange borders)
- Reactive hover states: `hover:bg-ohho-orange`, `hover:text-ohho-gold`, `group-hover:text-ohho-orange`
- Animated counter components for stats (48+, 100K+, 18+)
- Section divider gradients (orange→transparent)
